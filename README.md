# ShopSphere — E-Commerce Frontend

This project implements the uploaded Amazon-style frontend structure as a React + Vite frontend.

## Included
- Responsive global header/navigation/footer
- Home page with hero, categories, deals, recommendations
- Search and category listing pages
- Product detail page with gallery, variants area, buy box, wishlist and reviews
- Cart with quantity controls and order summary
- Multi-step checkout UI
- Order confirmation
- Account dashboard, orders, addresses, payments, wishlist and settings routes
- Login, registration and forgot-password screens
- Seller storefront
- Deals page
- Help center and FAQ
- 404 page
- Reusable components and localStorage cart/wishlist state

## Run

1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local Vite URL shown in the terminal.

## Important
This is a frontend implementation. Real authentication, database, payment gateway, inventory, order APIs, analytics, server-side SEO, and production backend services are not included because the supplied structure describes frontend requirements only.
